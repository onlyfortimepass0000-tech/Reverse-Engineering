# Alocana — Companion App & Subscriber Dashboard

Static concept site for **Alocana** ("Navigating Life, Together"): an AI wearable (smart cane / glasses) + on-demand human assistance + caregiver companion app.

- **Companion App** — interactive phone mockup (Home, Alerts, Reports, Settings tabs).
- **Free vs Alocana Plus toggle** — shows what unlocks when a family subscribes.
- **Subscriber Dashboard** — caregiver web view: KPIs, hazard & response-time charts, devices, safe zones, assistance log.
- **Plans** — Free + Pay-Go, Alocana Plus, Institutions (illustrative pricing).

Plain HTML/CSS/JS, no build step. Open `index.html` or deploy the folder as-is to Vercel.
Deep link a plan with `?plan=plus` or `?plan=free`. All data is sample data.

Live: https://alocana.vercel.app
